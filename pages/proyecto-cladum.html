Explorador de biodiversidad ⚙En desarrollo

Cladum

Explorador de biodiversidad en JavaScript Vanilla moderno, pensado para consumir la API pública de GBIF. Conecta mi formación en Biología con el desarrollo front-end: hoy tiene la estructura, los filtros y el diseño listos — la búsqueda real de especies todavía está en construcción.

Objetivo

Construir, fase por fase, un explorador de biodiversidad real: primero la estructura visual, después la lógica de datos con la API de GBIF, y por último favoritos y accesibilidad — todo en JavaScript Vanilla moderno, sin frameworks.
