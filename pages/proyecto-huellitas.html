Objetivo (consigna del curso)

Crear un ecommerce con HTML, CSS y conceptos de interacción en el DOM: HTML semántico, layout con Flexbox y/o Grid (sin floats), metodología BEM, Sass como preprocesador, diseño 100% responsive, mínimo 3 funcionalidades de JavaScript y una estructura de carpetas ordenada.
